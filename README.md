Yadu's Library

A single-page website for a personal home library, styled like a terminal in the VS Code Dark+ theme.

Search the catalogue by title or author, with live results
Catalogue data comes from a Google Sheet
Admin login unlocks an "add book" helper and a private PDF reader
The PDF reader supports scroll and flip modes
PDFs are stored in a private Supabase bucket, so only the logged-in admin can read them

The whole project is one file: index.html.
